# Material and mesh thumbnails

EvoEngine renders material and mesh thumbnails with an isolated preview scene. Project-panel thumbnails use a
canonical 256x256 view with deterministic studio lighting and a cool blue-gray environment background. Material
previews use Hazel-style bloom so emissive colors spill around the sphere and softly influence the studio background,
and the sphere fills approximately 70% of the image height. The preview path uses deterministic ACES tone mapping at
exposure 1.0. Interactive inspector previews remain 512x512 and are kept in memory so rotating or zooming a preview
does not create persistent variants.

Canonical thumbnails are stored under `<project>/Cache/Thumbnail/`. The cache is generated data, is never scanned as
project assets, and may be deleted at any time; EvoEngine recreates it as needed. Projects using source control should
include the following entry in their `.gitignore`:

```gitignore
/Cache/
```

Cache entries are invalidated when their source asset, referenced material textures, preview settings, or renderer
revision changes. Obsolete and missing-asset entries are removed automatically, and least-recently-used entries are
removed when the thumbnail cache exceeds 512 MB.

The studio environment at
`EvoEngine_SDK/Internals/DefaultResources/Textures/MaterialPreview/neutral_studio.hdr` is procedurally generated by
`Scripts/generate_material_preview_hdr.py`. It contains no third-party imagery and is distributed under CC0 1.0.

For deterministic visual checks, the Editor can render a saved material through the same provider and cache path:

```powershell
EvoEngineEditor.exe --project <project.eveproj> --capture-material-thumbnail <Assets-relative.evematerial> <output.png>
```
